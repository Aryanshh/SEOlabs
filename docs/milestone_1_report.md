## 1. EXECUTIVE SUMMARY & ACADEMIC SCOPE

The **SEO Experiment Lab** project addresses a fundamental structural deficiency in digital marketing and search engine optimization education: the reliance on superstition, post-hoc correlation, and unverified assumptions. 

Search engines operate on dynamic mathematical algorithms—including **Google RankBrain**, **Helpful Content Systems**, **Information Gain Scoring**, and modern **Generative Engine Optimization (GEO)** for AI Overviews. Traditional Conversion Rate Optimization (CRO) split-testing tools cannot be applied directly to SEO because crawlers evaluate complete URLs rather than user sessions, risking cloaking penalties.

To fulfill the rigorous technical and analytical requirements of Milestone I, our project deploys a **dual-engine architecture**:
1. **Apex Domain (`seolabs.space`)**: A custom full-stack web application—the **SEOlabs Algorithmic SERP Flight Simulator**—built with Next.js 14, React 18, Tailwind CSS, Prisma SQLite, and Google Gemini Pro AI analysis. It provides interactive pixel-width snippet truncation testing, two-proportion z-test A/B arena simulations, and algorithmic tier gamification.
2. **Subdomain (`app.seolabs.space`)**: A high-performance WordPress CMS instance powered by a hardened LEMP stack (Nginx, MariaDB, PHP 8.3 FPM) on AWS Lightsail, serving as the academic educational resource and content publishing repository for long-form pillar guides, Rank Math schema markup, and Core Web Vitals optimization.

- Core Google algorithm rollouts and Helpful Content updates.

Enterprise solutions (e.g. SearchPilot) require \$3,000+/month contracts and 50,000+ monthly visits per template, locking out the entire educational and small-medium business ecosystem.

### 9.2 Virtual Memory Hardening (2GB Swap File)
Because the Lightsail instance is configured with 512 MB of physical RAM, executing `npm run build` with SWC and Webpack compilers requires temporary virtual memory to avoid kernel Out-Of-Memory (OOM) termination. 

We provisioned and mounted a dedicated 2GB swap space:
```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```
*Live kernel verification:* When queried, the kernel returns `Text file busy` and `error: /swapfile is mounted`, validating that 2,048 MB of virtual memory is actively committed.

### 9.3 Production Dual-Application Architecture (Nginx Reverse Proxy)

To deliver both the interactive React web application and the academic WordPress CMS on the same server, Nginx acts as an intelligent traffic director:

#### Nginx Virtual Host 1: Apex Domain (`seolabs.space` $\rightarrow$ Next.js Flight Simulator)
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name seolabs.space www.seolabs.space;

    gzip on;
    gzip_comp_level 6;
    gzip_types text/plain text/css application/json application/javascript text/xml image/svg+xml;

    location /_next/static {
        proxy_pass http://127.0.0.1:3000;
        expires 365d;
        access_log off;
    }

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

#### Nginx Virtual Host 2: Subdomain (`app.seolabs.space` $\rightarrow$ WordPress LEMP)
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name app.seolabs.space;

    root /var/www/seolabs.space;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```
